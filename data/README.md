# data/

Datasets. **Everything in here except this README is git-ignored.**

- **raw/**: Files exactly as downloaded or recorded: Big Data Bowl CSVs, nflverse play-by-play, video clips, labeled images. Never edit these by hand.
- **processed/**: Cleaned or transformed data made from `raw/` by scripts, such as extracted frames, training splits, or merged tracking + play-by-play tables. You can delete it and regenerate it at any time.

NFL footage is copyrighted. Personal use only. Never commit videos or frames.
